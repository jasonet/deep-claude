# Contributing

This is a personal project maintained solely by [@jasonet](https://github.com/jasonet).

**External contributions are not accepted.** Issues, pull requests, and the wiki
are disabled. Pull requests opened from forks will not be reviewed or merged.

You are welcome to:

- ⭐ Star this repository
- 🍴 Fork it and modify your own copy freely under the [MIT License](LICENSE)

If you find a bug or want a feature, the recommended path is to fork this
repository and apply your own changes — that is what the MIT license is for.
